# 历程与联系

## 初始阶段到阶段二

```
━━━━ 阶段 A（ALU 完善）━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ALU/alu.py ──▶ ALU/full_adder.py ──▶ ALU/gate.py（原有）
    ▲ 组合塔至此成型：gate → 加法器 → ALU
    └─ test_alu.py（197 万项断言）

━━━━ 阶段 B（SEQ 骨架）━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  SEQ/register.py ──▶ SEQ/dff.py
    └─ 时序塔立起，但——
      ★ 此时两塔之间 import 数 = 0，完全独立

━━━━ 阶段 C（阶段二）━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  COMB/decoder.py ──▶ ALU.gate          （组合塔补件）
  COMB/mux.py ──▶ COMB.decoder, ALU.gate

  SEQ/register_file.py ─▶ SEQ.register          ┐
                    └────▶ COMB.mux/decoder ─────┼─★ 跨塔边 ①（间接：经 COMB 抵达 gate）
  SEQ/pc.py ─▶ SEQ.register                     │
           └─▶ ALU.full_adder（add8）───────────┼─★ 跨塔边 ②（直接）
  MEM/ram.py ─▶（无依赖，独立）                  ┘
```

**两塔独立生长 + 延迟合流 + 小开口对接 = 风险控制。** 两塔合流是全项目不确定性最大的事件（组合世界和时序世界如何咬合）。策略是：让两边各自长到稳定并有测试覆盖之后才碰面，且碰面接口收窄到仅两条边（一个借加法器、一个借选择阵列）。万一合流出问题，排查面就只有这两个接触点。
